# Three-minute researcher demo

1. State the question: can we replace a harmful branch while retaining verified work?
2. Show the 13 workers and source measurements. Explain the capability boundary:
   these workers cannot open GitHub, files, browsers, or the experiment design.
3. Start the event timeline. Point out the seeded invalid route and its descendants.
   This is a deliberately scripted mechanics demonstration, not emergent misalignment.
4. Stop on quarantine: raw content becomes unavailable, dependency descendants are
   held, unrelated work remains. Reading the route does not sanction the reader.
5. Stop on a reviewer-confirmed cull and replacement. The old generation is revoked;
   the replacement receives a short goal/assignment and approved graph IDs.
6. Advance to continued submissions. Show retained correct work and successful recovery.
7. Show A–F fixture results and live Jev diagnostic results separately. Explain the
   uncertainty: tiny provisional labels, no qualified live culling, incomplete
   RH-Detect example review, and untouched AI Village holdout.

The repository and demo remain researcher-only. The project is not submitted to haidaa.
Do not claim that BladeGraph solves swarm alignment or that fixture differences are
measured causal effects in real LLM swarms.
